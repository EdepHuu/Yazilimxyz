# 👕 Yazilimxyz - Clothing E-Commerce Platform

A modern clothing e-commerce platform where customers can browse products and place orders, store managers can add products and track inventory, and the support team can provide real-time assistance.

## 👥 Team Members
The project was developed by a dedicated and well-structured team, each member contributing with their own expertise:

1. **Team Leader – Mehmet Zahit Uyanık**  
   Responsible for overall project planning, coordination between backend & frontend, and full-stack contributions.  
2. **Backend Team Leader – Metehan Dündar**  
   Led the backend architecture, designed layered structure, and ensured API scalability and security.  
3. **Backend Developers – Gülendam Çetin, Harun İder**  
   Focused on implementing core business logic, database operations, and API integrations.  
4. **Frontend Developers – Büşra Çoğul, Elif Yılmaz**  
   Built modern, responsive UI components and implemented user experience features using React and Next.js.  

---

## 🛠️ Technologies Used
- **Frontend:** React.js, Next.js (App Router, SSR), Tailwind CSS, Zustand  
- **Backend:** .NET 8 Web API (running on port **7206**), RESTful architecture, Entity Framework Core  
- **Database:** SQL Server (hosted on an online server)  
- **Authentication:** Identity + JWT  
- **Real-Time Communication:** SignalR (Live chat and instant notifications)  
- **Frontend Port:** 3000  

---

## 🧩 Module Structure

### Customer Panel
- Product categories and advanced filtering (size, color, gender)  
- Product detail page and add-to-cart functionality  
- Order creation and order history  
- Real-time support via SignalR  

### Merchant Panel
- Add / update products  
- Order management (Processing, Shipped, Delivered, etc.)  
- Variant & stock management  

### Support Panel
- Real-time messaging with customers (SignalR)  
- Online / offline status tracking  
- Message history and predefined responses  

---

## 📌 Branch Strategy
- Development is done on the `develop` branch.  
- Each developer works on their own feature branch.  
- Code is merged via PR into `develop`, then into `main` after review.  

---

## 🚀 Roadmap (Completed)

- Authentication and authorization system  
- Product / order / variant / stock management  
- Admin, customer, and merchant panels  
- Real-time communication with SignalR  
- CI/CD integration and demo deployment (Vercel + Azure)

# 👕 Yazilimxyz - Giyim E-Ticaret Platformu

Kullanıcıların ürünleri inceleyip sipariş verebildiği, mağaza yöneticilerinin ürün ekleyip stok takibi yapabildiği ve destek biriminin gerçek zamanlı destek sunabildiği modern bir giyim e-ticaret platformudur.

2. **Backend Takım Lideri – Metehan Dündar**

## 🛠️ Kullanılan Teknolojiler
