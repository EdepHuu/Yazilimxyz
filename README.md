# 👕 Yazilimxyz - Giyim E-Ticaret Platformu

Kullanıcıların ürünleri inceleyip sipariş verebildiği, mağaza yöneticilerinin ürün ekleyip stok takibi yapabildiği modern bir giyim e-ticaret platformudur.

## 🛠️ Kullanılan Teknolojiler
- **Frontend:** React.js, Next.js (App Router, SSR), Tailwind CSS, Zustand  
- **Backend:** .NET 8 Web API, RESTful mimari, Entity Framework Core  
- **Veritabanı:** SQL Server  
- **Kimlik Doğrulama:** Identity + JWT  

## 🧩 Modül Yapısı

### Müşteri Paneli
- Ürün kategorileri ve gelişmiş filtreleme (beden, renk, cinsiyet)  
- Ürün detay sayfası ve sepete ekleme  
- Sipariş oluşturma ve sipariş geçmişi görüntüleme  

### Mağaza Paneli
- Ürün ekleme / güncelleme  
- Sipariş yönetimi (Hazırlanıyor, Kargoda, Teslim Edildi vb.)  
- Varyant & stok yönetimi  

## 📌 Branch Stratejisi
> Geliştirme `develop` branch’inde yapılır.  
> Her geliştirici kendi feature branch’inde çalışır.  
> Kodlar PR ile `develop` → kontrol sonrası `main`’e merge edilir.  

## 🚀 Yol Haritası (Tamamlananlar)
- Katmanlı mimari kurulumu  
- Authentication ve yetkilendirme sistemi  
- Ürün / sipariş / varyant / stok yönetimi  
- Admin, müşteri ve mağaza panelleri  
- CI/CD entegrasyonu ve demo yayını (Vercel + Azure)

# 👕 Yazilimxyz - Clothing E-Commerce Platform

A modern clothing e-commerce platform where customers can browse products and place orders, store managers can add products and track inventory, and the support team can handle customer requests efficiently.

## 🛠️ Technologies Used
- **Frontend:** React.js, Next.js (App Router, SSR), Tailwind CSS, Zustand  
- **Backend:** .NET 8 Web API, RESTful architecture, Entity Framework Core  
- **Database:** SQL Server  
- **Authentication:** Identity + JWT  

## 🧩 Module Structure

### Customer Panel
- Product categories and advanced filtering (size, color, gender)  
- Product detail page and add-to-cart functionality  
- Order creation and order history  

### Merchant Panel
- Add / update products  
- Order management (Processing, Shipped, Delivered, etc.)  
- Variant & stock management  

## 📌 Branch Strategy
> Development is done on the `develop` branch.  
> Each developer works on their own feature branch.  
> Code is merged via PR into `develop`, then into `main` after review.  

## 🚀 Roadmap (Completed)
- Layered architecture implementation  
- Authentication and authorization system  
- Product / order / variant / stock management  
- Admin, customer, and merchant panels  
- CI/CD integration and demo deployment (Vercel + Azure)
